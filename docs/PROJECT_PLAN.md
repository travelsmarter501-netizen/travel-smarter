- **Phase 5b — Prague quality gaps (2026-11-07, engine-ready, still not public).**
  - **Areas that are not neighbours in one day (12 hops in the audit, e.g. Kampa → Vyšehrad, Petřín Tower → Old Town Square):** fixed with an optional city hook (`CityPlannerModule.repairDayGeography`, implemented once in `lib/planner/cityGeographyRepair.ts` for Prague and later cities; Barcelona does not use it). After the day passes it swaps or moves one stop between days when that makes the broken day fully linked, within the engine's own limits (420 min, 6 stops, 3 areas), never making a day thinner and never putting a place on a day it is closed; the set of places in the trip is unchanged. It also orders a run of stops inside one area by the direction you arrive from (never moving a morning place later or an evening/sunset place earlier). Charles Bridge counts as the link between Malá Strana and the Old Town. Example: 1-day trip now Petřín Tower → Charles Bridge → Old Town Square (was Old Town Square, then back to the bridge).
  - **"Surprise Me" variety check classified Prague's shopping stops as food:** the shared helper read Barcelona's guide; it now takes the city's own places and protected flagships (`compositionProtectedPlaceIds`; Prague Castle, Charles Bridge, Old Town Square are never moved by that pass). Barcelona keeps its own defaults.
  - **Verified:** Prague audit (126 plans): hops between non-neighbouring areas 12 → 0, late days 0, no capacity shortfall, no duplicates, no closed-day or out-of-hours visit, total estimated travel 19,906 → 19,757 minutes, 28 of 126 plans changed; Barcelona engine output byte-identical (87 plans); browser suites on the build with these changes: plan languages 92/92, part 3 56/56, Prague 18/18, customer journey 21/21.
